### 核心技術

```css

/* 定義所有原始色票 */
:root {
  --systemRed-light: #ff3b30;
  --systemRed-dark:  #ff453a;
  --systemRed-increasedContrastLight: #d70015;
  --systemRed-increasedContrastDark:  #ff6961;
}

/* 依主題重新指向 */
:root[data-theme="light"] {
  --systemRed: var(--systemRed-light);
}
:root[data-theme="dark"] {
  --systemRed: var(--systemRed-dark);
}

/* 使用時永遠只用 --systemRed */
.danger { color: var(--systemRed); }

/* 在 .js 中只用 document.documentElement.setAttribute('data-theme', 'dark'); */

```
