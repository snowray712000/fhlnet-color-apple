Table Color Demo

@fhlnet/color-apple — 示範 Apple iOS 系統色在 table 上的應用

使用的 CSS 變數

html bg — --systemGroupedBackground
table bg — --secondarySystemGroupedBackground
header / even row — --tertiarySystemGroupedBackground
divider — --separator

範例：產品列表

變數對照表（table with accent header）

角色 CSS 變數 說明
頁面底色 --systemGroupedBackground html / body 背景
Table 背景 --secondarySystemGroupedBackground card / table 容器
Header 背景 --tertiarySystemGroupedBackground thead 背景
Cell 背景（奇） --secondarySystemGroupedBackground 奇數 row（與 table 同）
Cell 背景（偶） --tertiarySystemGroupedBackground 偶數 row 交錯色
分隔線 --separator row border
文字 --label 主要文字
輔助文字 --secondaryLabel 說明、副標
